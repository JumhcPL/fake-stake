# ONYX Casino Demo

Responsywne lobby kasyna inspirowane estetyką serwisów gamingowych. Własna marka, polski interfejs, cztery gry (Dice, Coin Flip, Roulette, Neon Fruits), ulubione, lokalne saldo i historia rund.

Wyłącznie wirtualne żetony bez wartości pieniężnej. Bez wpłat, wypłat i integracji ze Stake. Wyniki powstają lokalnie z użyciem Web Crypto; to demonstracja, nie system do gry na pieniądze. Saldo zapisane w localStorage można zmieniać i nie jest zabezpieczone serwerowo.

## GitHub Pages

1. Utwórz repozytorium GitHub i prześlij całą zawartość tego folderu (łącznie z `.github`).
2. W repozytorium wybierz **Settings → Pages → Source → GitHub Actions**.
3. Uruchom workflow **Deploy GitHub Pages** w zakładce Actions lub wypchnij zmianę na `main`.
4. Gotowy adres pojawi się w wyniku zadania `deploy`.

Workflow publikuje tylko pliki strony, bez README i pozostałych plików repozytorium. Nie wymaga instalowania zależności ani kluczy API. Fonty Google są opcjonalne — dostępne są fonty systemowe.

## Lokalnie

Otwórz `index.html` w aktualnej przeglądarce albo uruchom dowolny lokalny serwer plików statycznych. Nie ma etapu budowania.
